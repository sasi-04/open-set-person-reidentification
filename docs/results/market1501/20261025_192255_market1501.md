# OpenID Vision - evaluation report

*Know when to match. Know when to reject.* Independent technical prototype responding to the Zed Digital PS-1 assignment; not an official Zed Digital product. A similarity score is not a probability and a match is not proof of identity.

## Overview

Dataset **market1501** (benchmark; 1501 identities, 26051 images). Operating target: **DIR@1 (accepted and correct) >= 60.0%, minimise FAR**. Seeds: 0, 1, 2. Model: OSNet x1.0 (multi-source) (official osnet_x1_0_ms_d_c.pt) on cpu.

## How to read this report

FAR is query-level: a stranger counts as falsely accepted whenever the system names ANY enrolled person for them.

A threshold selected on one calibration sample does not guarantee the same FAR for new people; the confidence interval and the calibration sample size show how much to trust it.

Results are for the dataset, split and seeds above. They do not demonstrate demographic fairness, privacy compliance or production readiness.
