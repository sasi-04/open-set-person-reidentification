# Implementation plan and status

*What was planned after the requirement audit ([REQUIREMENT_AUDIT.md](REQUIREMENT_AUDIT.md)), in priority order, with what actually happened.*

| # | Step | Why | Status |
|---|---|---|---|
| 1 | Verify the embedding model on real cross-camera data | the whole system depends on it; earlier tests never measured discrimination | **DONE** - Rank-1 20 % found; cause isolated to the weight file ([MODEL_VERIFICATION.md](MODEL_VERIFICATION.md)) |
| 2 | Replace it with a verified, hash-pinned model; keep the safe loader | restore a working core | **DONE** - OSNet x1.0 official checkpoint, converted once, pinned by tensor digest; registry flags the failed files; 431 tests pass |
| 3 | Obtain a public benchmark and record provenance and licence | PS-1 asks for FAR at fixed recall on a public benchmark | **DONE** - Market-1501 (third-party copy, no official query set) |
| 4 | Run the evaluation: 5 recall targets × 3 seeds, identity-disjoint, thresholds from calibration people only | the core measurement | **DONE** - [EXPERIMENT_RESULTS.md](EXPERIMENT_RESULTS.md) |
| 5 | Ablations: margin, confidence, flip, average aggregation | find what actually reduces FAR | **DONE** - margin/confidence/flip no gain; average aggregation promising (noisy) |
| 6 | Metric-learning fine-tune with leakage guard, evaluate on held-out people | lower FAR at high recall | **DONE for seed 0** (Rank-1 83.1 → 89.7 %, FAR at 70 % recall 22.2 → 11.4 %); seeds 1-2 `NOT_RUN` |
| 7 | Re-measure the home-page example and update every quoted number | no stale claims | **DONE** (example docs, README, traceability) |
| 8 | Honest documentation: protocol, algorithm, API (generated), limitations, audit | reviewer-facing clarity | **DONE** |
| 9 | Rebuild the 30-page manual, jury deck and HR script with the new numbers | the older PDFs quote pre-fix scores | **OPEN** - the Markdown documents are authoritative; the PDFs are regenerated by `scripts/build_*` |
| 10 | Docker packaging | deployment | **NOT_DONE** (not requested by the audit's priorities) |
| 11 | Face + body benchmark on pedestrian data with faces | the product's actual strategy | **NOT_DONE** - needs a dataset with usable faces and consent/licence review |
| 12 | Fine-tune seeds 1-2, full-backbone fine-tune, second dataset | confidence in the fine-tuning gain | **NOT_RUN** (≈45 min per seed on this CPU) |

Rule followed throughout: change one thing, run the relevant tests, measure, record - including the results that did not help.
